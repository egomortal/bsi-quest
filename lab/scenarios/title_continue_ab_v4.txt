# BSI-Quest lab scenario v4 (build 78): v3 + the missing "Sign In" press (j0006 screenshots).
# v3 note: Menu flow on the Quest, from j0005 screenshots (19 Oct):
#   startup movies (~35 s, skipped here via skip_intro.txt) -> "PRESS ANY KEY" -> "Login Failed" dialog
#   (A = EXIT GAME, B = Proceed Without Login) -> "Sign In" dialog (A = Yes, sign in) -> main menu (Main Game first)
#   -> Main Game sign (CONTINUE / NEW GAME / LOAD CHAPTER, Continue first).
# The "saved-game populate task" log line comes ~11 s after start on its own: it is NOT a sign of the title press.
on_timeout quit
wait_map XEntry_P 300
mark title_map
wait 20
mark press_any_key
press A
wait 8
mark login_failed
# B = Proceed Without Login (A here would exit the game)
press B 200
wait 8
mark sign_in
# Sign In dialog: A = Yes, sign in
press A
wait 8
mark main_menu
press A
wait 8
mark main_game_sign
# Continue (first entry)
press A
on_timeout continue
wait_map_not XEntry_P 150
on_timeout quit
mark loading
wait_map Master_P 300
wait 45
mark static_default
wait 60

wait 60
